How this works

The paper (PDF, §7) finds that the eRST label adversative-antithesis barely tracks formal balance. The 80-pair audit had only eight such rows, too few to tell two explanations apart: either the label is loose, or real antitheses carry their opposition in meaning rather than in balanced form. These 40 pairs start that test.

  1. Read the context. Unit A is highlighted in blue, unit B in amber. The sentence before and after are greyed.
  2. Answer the three questions. Each is yes, no, or uncertain. The definitions under each question are the current codebook, which is what we're testing.
  3. Where the categories don't fit the item, say so. "What would you call it?" and "Where does the rubric fail?" are the fields that matter most at this stage. A short phrase is enough.
  4. Code independently. Everyone gets the same 40 so we can see where coders agree and where the categories cause disagreement.
  5. When you're done (or want to send a partial batch), press Copy my codes and paste the result into an email reply.

Classical antithesis? Opposed meanings presented in comparable cola or comparable syntactic slots. Code no for scalar comparison alone, ordinary instead of / rather than alternatives, concession, dialogue repair, or negation without balanced opposed presentation.
Semantic opposition? The units encode opposed alternatives, properties, states, choices, or scalar contrasts, even if the form isn't balanced. Code no when the units don't clearly oppose each other.
Parallel opposition? The opposition is carried by matched grammatical frames, slot substitution, or a clear paired construction. Code no when only a contrast marker connects structurally unlike spans.
